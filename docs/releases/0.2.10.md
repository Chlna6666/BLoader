# BLoader 0.2.10

发布日期：2026-08-01

## Rich Presence 修复

- 将 Rich Presence 兜底层从扫描 `XblPresenceSetPresenceAsync` 导出改为 XUser Token 请求边界。
- 修复 Minecraft 将 XSAPI 静态链接进主程序、进程中不存在可供 `GetProcAddress` 定位的 `XblPresenceSetPresenceAsync` 导出时，0.2.9 Presence Bridge 只启动但从未安装 Hook 的问题。
- 捕获 XSAPI 发往 `userpresence.xboxlive.com` 的原始 POST/DELETE 请求与 JSON 正文，保留 Minecraft 生成的 SCID、Presence ID、Token 参数和 active/inactive 状态。
- 独立重放时将 URL 中的用户标识重写为 BMCBL 安全会话的 XUID，避免系统账户与自定义账户混用。
- 使用 Xbox 默认签名策略：Signature Policy v1、无 ExtraHeaders、最多签入正文前 8192 字节。
- Presence 请求采用 latest-wins 队列；被替换和完成的正文通过 `Zeroizing` 清理。

## 诊断变化

- 停止每 50ms 扫描 XSAPI 模块导出，移除误导性的“将接管 XblPresenceSetPresenceAsync”启动日志。
- 最多记录前 24 个 XUser Token 路由，只包含序号、HTTP 方法、目标 Host 和正文长度。
- 不记录 URL 路径、XUID、Header 值、Authorization、Signature、Token、私钥或请求正文。
- 成功捕获 Presence 时输出 `Token Presence Relay 已捕获 XSAPI Presence 请求`。
- 独立提交成功时输出 `Token Presence Relay 已提交 Xbox 状态 | http_status=...`。

## 版本

- BLoader 版本更新为 `0.2.10`。
