# BLoader 0.2.64

0.2.64 发布 0.2.63 引入的跨账号 Microsoft Runtime 用户凭据覆盖链，并包含随后提交的测试夹具整理。运行时认证逻辑与 0.2.63 的目标保持一致：

- 同账号继续完全复用 Microsoft Runtime；
- 跨账号不使用 BMCBL 预生成 XSTS/PoP key 回退；
- BLoader Hook native XUser MSA credential slots 39/40/41，以 BMCBL 目标账号的短期 MSA access token 替换 backing user 的用户凭据来源；
- Microsoft Runtime 继续负责 DToken、TToken、最终 XSTS、缓存和 Signature；
- 最终 XSTS 必须解析出与 BMCBL custom XUID 一致的 `xid` 才允许返回，否则结果缓冲区会被清零并 fail-closed；
- MSA refresh token 始终保留在 BMCBL 进程/凭据存储中。
