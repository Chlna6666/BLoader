# BLoader 0.2.78 — 统一原生控制台日志兼容性

- 在原生预加载前激活控制台日志 Sink，不在 OEP 前修改进程 stdout/stderr。
- 主动兼容独立原生 DLL 对 Win32 `WriteConsoleW`、`WriteConsoleA` 和控制台型 `WriteFile` 的输出；不要求第三方接入 BLoader SDK。非控制台文件、管道、异步 I/O 保留原始 Win32 行为。
- 保留已关联的 Win32 标准控制台句柄，仅按既有路径重定向 CRT stdout/stderr，避免独立 DLL 的 `GetConsoleMode` 误判。
- 控制台显示毫秒时间戳与输出序号，现有写入锁保证完整结构化行串行写入；早期 BLoader 事件原始时间写入日志文件，XUser 早期事件回放保留发生时间。
- 保持无文件写入的旧版 UWP 行为，避免直接更改其他第三方 Mod。

## 验证建议

在 Windows x64 Release 模式执行 `cargo test --lib` 与 `cargo build --release --lib`，通过 Cosmetics 预加载及持续 WinHTTP 日志验证写入顺序、日志归属、无重复输出、原生控制台句柄可见性。对跨线程、部分写入、二进制 Win32 输出进行回归。
