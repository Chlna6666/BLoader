# BLoader 0.2.68

## XUser / Xbox authentication diagnostics

- Installs a transparent forwarding probe on the high-confidence Microsoft Runtime pre-XSTS builder function discovered from the unique `UserTokens` xref.
- Logs only non-secret call-shape metadata for the first few invocations: thread id, raw argument values, memory mapping classification, whether an argument points inside `xgameruntime.dll`, and the original return value class.
- Does not read pointed-to memory, JSON strings, UToken, DToken, TToken, XSTS, signatures or request bodies.
- Keeps cross-account and no-system-account authentication fail-closed until the probed ABI proves where the official builder receives its `UserTokens` container.

This release is intended to identify the pre-XSTS builder calling convention before any UToken mutation hook is installed.
