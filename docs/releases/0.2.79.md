# BLoader 0.2.79 — 紧凑控制台日志

本次调整在 0.2.78 的原生 Mod 日志兼容能力基础上，减少 Windows 控制台的横向占用：

- 控制台显示 `[10:09:04 INFO] [Cosmetics] ...`，不再显示毫秒与 `#000001` 事件序号。
- 保留内部毫秒级事件时间、早期日志缓冲排序和结构化日志的串行写入机制。
- `latest.log` / 归档日志继续保留详细时间与线程信息，不改变第三方原生 Mod 的加载与写入兼容行为。
- 增加验证控制台紧凑格式的单元测试。

## 验证

通过 Windows x64 的 `cargo test --lib`、`cargo build --release --lib` 及 DLL 导出验证后发布。
