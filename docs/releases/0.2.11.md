# BLoader 0.2.11

## Changed

- 删除 Token Presence Relay，不再在 `XUserGetTokenAndSignatureAsync` / `XUserGetTokenAndSignatureUtf16Async` 边界捕获并独立重放 `userpresence.xboxlive.com` 请求。
- 删除 `presence_token.rs` 中的 WinHTTP Presence 提交、后台队列、请求重写和相关诊断日志。
- 保留 `QueryApiImpl` Hook、自定义 Rust XUser、Token 路由和 Proof-of-Possession Signature 主链。
- 后续 Presence 支持将基于官方 Windows Runtime 的 DToken/TToken 与 BMCBL 自定义 UToken 组合方案重新设计。

## Fixed

- 停止使用通用 `http://xboxlive.com` Profile XSTS 独立提交 Minecraft for Windows Rich Presence，避免持续产生 HTTP 403 和重复网络请求。

## Version

- BLoader 版本更新为 `0.2.11`。
