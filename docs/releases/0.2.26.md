# BLoader 0.2.26

Diagnostic gate-only build for legacy UWP startup isolation.

This build starts from the proven 0.2.25 minimal static-attach baseline and restores only:

- the one-byte Minecraft OEP `INT3` gate;
- early VEH / unhandled / CRT crash-handler registration, with inert diagnostic callbacks;
- XState-aware `InitializeContext` + `CopyContext` and `RtlRestoreContext` round-trip back to the original Minecraft OEP.

All other BLoader runtime behavior remains disabled: no tracing, stdio capture, config loading, XUser bridge, MinHook, file/network redirection, PreLoader, Mod loading, runtime-ready worker, console, or worker threads.

The purpose of this build is diagnostic: if Minecraft 1.18.30 UWP fails while 0.2.25 succeeds, the failure is isolated to the OEP/exception/context gate surface rather than BLoader's normal runtime services.
