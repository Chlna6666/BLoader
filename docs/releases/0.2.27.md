# BLoader 0.2.27 diagnostic

This diagnostic build keeps the proven 0.2.26 gate-only startup path and restores the full in-process crash reporter implementation.

Enabled at process attach:
- SetCurrentDirectoryW to the Minecraft executable directory
- full crash_report::install_early()
- crash reporter VEH, top-level SEH filter, CRT invalid-parameter and purecall handlers
- real crash text/JSON/minidump/symbolization code paths
- OEP INT3 gate
- XState-aware InitializeContext/CopyContext round-trip
- RtlRestoreContext back to the original Minecraft OEP

Still disabled: config, XUser bridge, MinHook, stdio capture installation, file/network hooks, PreLoader, Mods, runtime-ready workers, graphics hooks and all other bootstrap services.

The external crash logger process is intentionally not spawned in this isolation build; only the complete in-process crash reporter is restored.
