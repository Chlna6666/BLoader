# BLoader 0.2.13

## 主要变更

- 增加 Wine 运行环境检测与启动诊断日志。
- 修复 0.2.12 将 `XUserCloseHandle` 引用计数归零错误解释为 Xbox 用户注销的问题。
- `XUserCloseHandle` 现在只释放标题持有的用户句柄，不再驱动 `SigningOut`。
- `XUserFindUserById` 和 `XUserFindUserByLocalId` 不再因为诊断句柄计数暂时归零而把已认证用户判定为离线。
- 在最后一个 `XUserRegisterForChangeEvent` 订阅注销前派发 `SigningOut`，使 XSAPI 能在回调仍然有效时执行 Presence 和会话清理。
- Hook `ntdll!RtlExitUserProcess`，在正常进程退出前补发 `SigningOut -> SignedOut` 生命周期。
- 正常退出最多等待 2 秒 sign-out deferral；超时后记录明确诊断并继续退出。

## 预期日志

正常运行：

```text
XUser 变更事件已注册 | registration_token=... | callback_count=...
已安装正常退出生命周期 Hook | target=ntdll!RtlExitUserProcess | ...
```

正常关闭游戏：

```text
最后一个 XUser 变更订阅正在注销；在移除回调前派发 SigningOut 生命周期
XUser 状态进入 SigningOut | trigger=last-change-registration-unregister | ...
XUser 注销回调与延迟已完成；XUser 状态进入 SignedOut
```

若游戏没有先注销订阅，则退出 Hook 兜底：

```text
检测到正常进程退出；正在提交 XUser 注销生命周期 | source=ntdll!RtlExitUserProcess
进程退出前 XUser 注销生命周期已完成
```

## 限制

强制结束进程、系统崩溃或外部 `TerminateProcess` 不保证执行进程内退出回调。本版本修复的是 Minecraft 正常关闭时的 XUser 注销生命周期。
