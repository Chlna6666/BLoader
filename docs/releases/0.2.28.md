# BLoader 0.2.28 no-disk runtime diagnostic

Restores the full BLoader runtime feature chain while removing BLoader-owned runtime diagnostic/status/log file creation from the Minecraft process.

Enabled again: XUser Bridge, MinHook-backed hooks, read-only config loading/watching, tracing to console/OutputDebugString, console, in-memory/pipe stdout and stderr capture, file redirection, network hooks, render Present observer, runtime readiness, PreLoader/LeviLamina delegation, BL/native/hot Mod loading.

The Minecraft process does not create BLoader log files, crash txt/json/dmp files, PreLoader/native status JSON, stdio capture files, or auto-rewrite config.json. Loose DLL discovery is read-only and no longer auto-packages or writes manifest.json. The launcher must provide an absolute redirection root outside the game/version directory.
