# BLoader 0.2.28 no-disk runtime diagnostic

Restores the normal runtime chain while eliminating BLoader-owned runtime diagnostic/status/log file creation from the Minecraft process.

Enabled: XUser Bridge, MinHook-backed XUser/file/network hooks, read-only config loading/watching, tracing to console and OutputDebugString, console, anonymous-pipe stdout/stderr capture, file redirection, network hooks, runtime_ready, PreLoader/LeviLamina delegation, and native/BL/hot Mod loading.

Graphics hooks remain disabled. Delayed Mods use OEP/process/window stability only; BLoader does not create a dummy HWND, graphics device, swapchain, or Present hook.

The Minecraft process does not create BLoader log files, crash txt/json/dmp files, PreLoader/native status JSON, stdio capture files, or auto-rewrite config.json. Loose DLL discovery is read-only and no longer auto-packages or generates manifest.json. Automatic data redirection requires an absolute launcher-provided target outside the game/version directory.
