# BLoader 0.2.76

- Fixed `latest.log` being forced to DEBUG detail when `log_level` was `info`; persistent and console logging now follow the configured level.
- Reclassified high-volume loader diagnostics as DEBUG so normal INFO logs keep actionable runtime output without diagnostic noise.
- Switched native stdout/stderr capture to anonymous memory pipes. `logs/captured-stdio` and raw capture files are no longer created, and old captured-stdio directories are removed on startup.
- Added `log_archive_days` to `config.json`, defaulting to 7 days. Only `logs/archive/bloader-*.log` files older than the configured retention are pruned.
- Removed standalone runtime snapshot output for `mod-registry.json`, `native-load-status.json`, and `preloader-status.json`; diagnostics remain available through `latest.log`, archive logs, and in-memory crash context.
- Startup removes obsolete snapshot files left by older BLoader versions.
