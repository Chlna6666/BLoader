# BLoader 0.2.80 — 统一 BL / Native Mod 控制台来源

修复 BL Mod 在独立线程通过宿主 `Host.log` 写入日志时的模块归属错误。例如此前的输出：

```text
[16:01:21 INFO] [BLoader/BL] [BLoader DevTools] UI_WINDOW_SHOWN_BY_DEFAULT
```

现在将已注册的 BL 模块来源统一为：

```text
[16:01:21 INFO] [BLoader DevTools] UI_WINDOW_SHOWN_BY_DEFAULT
```

- 优先使用 BL 回调中的活动模块身份；异步线程根据消息前缀匹配已注册的 BL 模块名/别名。
- 移除与确认模块名重复的日志正文前缀；未知来源保留通用 BL 标识而不随意归属。
- 不增加控制台毫秒或事件序号，也不要求修改第三方 Mod。
- 新增 4 个 BL 日志来源与前缀去重单元测试。

Windows x64 发布工作流将进行格式化、单元测试、Release 编译、DLL 导出验证和校验文件打包。
