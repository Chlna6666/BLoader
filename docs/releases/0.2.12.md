# BLoader 0.2.12

## Added

- 实现 `XUserRegisterForChangeEvent` 与 `XUserUnregisterForChangeEvent`，支持注册令牌、注销等待和回调执行状态跟踪。
- 实现 `XUserGetSignOutDeferral` 与 `XUserCloseSignOutDeferralHandle`，允许 XSAPI 在注销阶段完成 Presence 和会话清理。
- 为 `XUserHandle` 增加真实引用计数，并为重复、查找和关闭句柄补齐生命周期语义。

## Changed

- `XUserGetState` 不再永久返回 `SignedIn`，现在按 `SignedIn → SigningOut → SignedOut` 状态机返回。
- 最后一个用户句柄关闭时同步派发 `SigningOut`；所有 sign-out deferral 释放后派发 `SignedOut`。
- 保留注销阶段的 Token/Signature 能力，避免 XSAPI 的 Presence DELETE 因过早禁用认证而失败。

## Fixed

- 修复自定义 XUser 缺少关闭和状态变更生命周期，导致 Minecraft 退出后 Xbox 好友状态可能持续数小时显示仍在游戏的问题。

## Diagnostics

- 增加变更事件注册、句柄剩余引用数、`SigningOut` 和 `SignedOut` 状态日志。

## Version

- BLoader 版本更新为 `0.2.12`。
