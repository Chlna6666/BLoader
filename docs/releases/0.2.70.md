# BLoader 0.2.70

## 修复

- 跨账号 pre-XSTS 诊断 native token 请求现在强制设置 `XUSER_TOKEN_FORCE_REFRESH`，避免 Microsoft Runtime 直接返回缓存 XSTS 而不执行 `UserTokens`/`DeviceToken`/`TitleToken` 聚合路径。
- 诊断触发按 relying party 去重；同一 RP 已启动或完成诊断时不再重复 silent native Add，降低 `http://xboxlive.com` 重复请求造成的日志噪音和 native handle 压力。

## 安全边界

- 诊断结果继续丢弃，不返回给 Minecraft。
- 不读取、不输出 UToken、XSTS、Signature 或请求正文。
- 跨账号和无 matching native user 的认证路径仍然 fail-closed，直到 pre-XSTS UserTokens ABI 被确认。
