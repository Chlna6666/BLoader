# BLoader 0.2.71

## 诊断推进

- 在 `UserTokens` xref 后的 direct call target 上安装最多 8 个透明转发探针。
- 保留 0.2.70 的 `XUSER_TOKEN_FORCE_REFRESH` 诊断 native token 请求和 RP 去重。
- 当外层 `0x293490` builder 探针没有命中时，call-target 探针可确认真实执行路径是否直接进入内部 helper。

## 安全边界

- 探针继续只记录参数指针分类、线程、slot 和 target RVA。
- 不读取、不输出 UToken、XSTS、Signature、JSON 或请求正文。
- 仍然 fail-closed，不把 native A 的 token 返回给 Minecraft。
