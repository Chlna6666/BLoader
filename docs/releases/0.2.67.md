# BLoader 0.2.67

## XUser / Xbox authentication diagnostics

- Uses Windows x64 `RtlLookupFunctionEntry` metadata to map the unique `UserTokens` text reference in the official System32 `xgameruntime.dll` back to its real `RUNTIME_FUNCTION` boundary.
- Records only non-secret code-location diagnostics: function begin/end/unwind RVAs, the RIP-relative LEA destination register, co-located `DeviceToken` / `TitleToken` / XSTS reference counts, nearby direct-call candidate RVAs and a short SHA-256 code fingerprint.
- Does not log UToken, DToken, TToken, XSTS, request signatures or request bodies.
- Does not install a hook at the unresolved pre-XSTS builder yet. Cross-account and no-system-account token routes remain fail-closed until the builder calling convention is verified from runtime diagnostics.

This release is intended to turn the single observed `UserTokens` marker/xref into a stable function-level candidate before any mutation hook is installed.
