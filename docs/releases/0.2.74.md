# BLoader 0.2.74

## 配置边界

- 从 BLoader typed `Config` 删除未被运行逻辑使用的 `editor_mode`、`lock_mouse_on_launch`、`unlock_mouse_hotkey` 和 `reduce_pixels`。
- 旧 `config.json` 中上述字段会在 BLoader 配置同步时移除，不再被默认 schema 自动补回。
- 新增 `vanilla_skin_pack_redirect: Option<String>` 兼容字段，与 BMCBL 的版本配置协议保持一致；缺失或 `None` 表示不启用 vanilla skin pack 重定向。
- BLoader 写回配置时改为合并自己拥有的 typed 字段，保留 BMCBL/启动器拥有的未知顶层字段，避免 schema 同步删除 `shortcut_silent_launch` 等启动器配置。
- 保留 `file_redirections` 作为实际文件重定向规则来源；BMCBL 已负责将 vanilla skin pack 设置同步为对应的 directory rule。
