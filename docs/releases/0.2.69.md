# BLoader 0.2.69

## 变更

- 在跨账号 / 无同 XUID native 用户路径中，保留 fail-closed 策略，不把不匹配 native 用户的最终 Token 返回给 Minecraft。
- 当 Microsoft Runtime pre-XSTS builder 已经被高置信定位时，额外启动一次内部诊断链路：
  - `XUserAddAsync(AddDefaultUserSilently)` 仅作为诊断 native 能力句柄来源；
  - 使用原始 Minecraft URL 发起一次内部 native token async；
  - 目的仅是触发 0.2.68 已安装的 builder 透明探针，解析调用 ABI；
  - 不读取 Token / XSTS / Signature / JSON 正文；
  - 不把诊断结果返回给 Minecraft；
  - native 句柄在诊断完成或失败后关闭。

## 预期日志

- `pre-XSTS builder 诊断 native Add 已启动`
- `pre-XSTS builder 诊断 native 用户已建立`
- `pre-XSTS builder 诊断 native token 请求已启动`
- `pre-XSTS builder probe hit`
- `pre-XSTS builder probe return`
- `pre-XSTS builder 诊断 native token 请求完成并丢弃结果`

如果系统没有可 silent-add 的 Xbox 用户，诊断会输出 `diagnostic-skip`，BMCBL synthetic XUser 仍保持可用，跨账号 token 路由继续 fail-closed。
