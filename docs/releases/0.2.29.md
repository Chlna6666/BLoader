# BLoader 0.2.29 full file + debug diagnostics

This validation build restores the complete file-oriented runtime and the full disk-backed diagnostic stack on top of the startup chain proven working in 0.2.28.

Restored file behavior includes relative LocalState redirection, Win32/FromApp/NT file hooks, config persistence, PreLoader/native status files, loose-DLL packaging/manifest handling, BL cache paths, per-Mod/process stdio capture files, regular logs, crash text/JSON/minidumps, and the external crash logger.

Logging is forced to DEBUG for this validation build even if an older config.json still contains `log_level: info`. `logs/latest.log`, archived session logs, Mod logs and captured stdout/stderr are restored. File-redirection DEBUG output includes hook installation, redirect sequence, API, source/target path, CreateFile creation disposition, returned handles and Win32 errors.

Graphics hooks remain disabled. BLoader does not create a dummy HWND, D3D/DXGI device, swapchain or Present hook; delayed Mods continue to use runtime_ready.
